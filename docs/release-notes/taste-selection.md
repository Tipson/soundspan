# Настройка вкусов: обратная связь в левой колонке

## Изменение

Пустая колонка с обычной кнопкой заменена музыкальной композицией: волна в кольцах видна до первого выбора. При добавлении и удалении исполнителей плавно меняются высота полос, длина цветной дуги и заливка кнопки. Это декоративный отклик, не оценка качества рекомендаций и не обязательное количество выборов.

Под композицией видны четыре последних выбранных артиста и число остальных. Используются уже загруженные портреты, без новых запросов; при отсутствии изображения — инициалы. Счётчик по-прежнему учитывает весь выбор, ограничений количества нет.

Кнопка яркая фиолетовая с контрастным текстом: «Настроить под меня» → «Применить выбор» → «Сохраняем…». Сохранение одного исполнителя и очистка выбора доступны. На мобильной ширине декоративная композиция скрыта, нижняя кнопка и её заполнение сохранены. Reduced motion выключает переходы. На невысоком desktop левая колонка прокручивается независимо, действие доступно с клавиатуры.
