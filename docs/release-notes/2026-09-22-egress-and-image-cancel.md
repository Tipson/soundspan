# 2026-09-22 — Восстановление музыкального выхода и отмена загрузки обложек

## Причины и восстановление

С 04:05 MSK журналы пула фиксировали потерю SSH-каналов. Soundspan использовал старый адрес немецкого сервера 178.17.51.114; актуальный адрес из операторского SSH-профиля — 193.233.134.251. По аутентифицированному подключению подтверждены тот же ED25519 host key и ранее разрешённый публичный ключ Soundspan. Причина смены IP и её инициатор не установлены.

Изолированный тест с прежним ключом Soundspan и проверкой host key вернул HTTP 200 от music.youtube.com. Обновлены только music-soundspan-egress.service и soundspan-egress-pool-{1,2,3,4}.service, добавлен подтверждённый адрес в отдельный known_hosts. Не отключались TLS/SSH-проверки, не менялись ACL, сторонние VPN и Soulseek. Backup и защищённый от дрейфа откат: /srv/music/soundspan-releases/egress-address-20260922/rollback.py. Откат адреса вернёт неработающий старый маршрут, применять только осознанно.

Проверка через production ytmusic: радио по UY4_86-GaEI — HTTP 200, 5 треков, 1,35 секунды; разрешение потока — HTTP 200 за 1,05 секунды; фактический аудио Range — HTTP 206, 65 536 байт audio/webm, сигнатура 1a45dfa3. Страница /vibe в авторизованном браузере перешла из настройки в «Включить мою волну» без сообщения о недоступности. Пользовательская очередь не заменялась, воспроизведение не запускалось.

## Вторичный сбой API

На отказах обложек прокси возвращал 503. После cancel Readable.toWeb оставлял окно для позднего события data: enqueue в закрытый controller выбрасывал ERR_INVALID_STATE вне обработчика запроса. API завершался через uncaughtException и перезапускался (зафиксировано 20 рестартов).

Ошибка воспроизведена отдельно на Node и в четырёх регрессиях (503, 404, 302, отмена oversized 200). Заменён только адаптер тела approved image CDN на pull из async iterator с флагом отмены до destroy и подавлением завершения уже отменённого чтения. Таймаут Axios, HTTPS_PROXY/NO_PROXY, allowlist доменов, SSRF/DNS/redirect guard и лимит размера сохранены. Глобальные исключения не скрываются.

## Проверки и review

Целевые тесты до исправления: 4 регрессии красные с тем же ERR_INVALID_STATE. После исправления: 41 тест. Backend build и полный coverage: 8 808 passed, 9 skipped, 622 suites passed, 2 skipped. Дополнительная проверка позднего error после отмены выполняется перед выпуском.

Обычный и adversarial review: проверены отмена при ошибке/редиректе/лимите, stalled body timeout, late data/error, backpressure, граница доверенных доменов и закрытие upstream. Новых прав/источников/секретов не добавлено. Отдельный эксплуатационный долг: health-проверка локального процесса/порта не подтверждает работоспособность внешнего радио. Нужен ограниченный сквозной мониторинг и сверка адреса при инфраструктурной миграции; не считать это реализованным данным исправлением.
