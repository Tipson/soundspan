## Исправление

Таймер буферизации принимал решение по факту истечения срока, не проверяя
текущее положение аудио. Когда callbacks страницы задержаны, медиа может уже
продолжаться, а старый timeout ещё способен остановить его или запустить замену
источника. Перед этим действием монитор сравнивает живую позицию с позицией при
запуске таймера. При прогрессе применяется существующий путь восстановления.
При продолжающемся зависании сохраняются прежний deadline и обработка ошибки.

Это небольшое изменение общего монитора; правила ручной паузы, выбора источника,
доступа, очереди, VK и фоновой аудиосессии не меняются.
