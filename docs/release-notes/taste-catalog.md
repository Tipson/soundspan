# Каталог исполнителей в настройке вкусов

Вместо конечной подборки по жанрам используется постраничный каталог Last.fm: общий чарт или исполнители жанрового тега. Размер страницы — 48; новые страницы подгружаются у нижней границы списка. Общего искусственного лимита списка или выбранных артистов нет. При достижении конца каталога показано сообщение, поиск по имени остаётся доступным.

Повторы между страницами убираются. Смена фильтра отменяет старый запрос; выбор независим от карточек и сохраняется между фильтрами. Сохранённые жанры чередуются по одной странице, без одновременного запроса всех направлений. Ошибки позволяют повторить ту же страницу. Статическая подборка остаётся запасным вариантом с явным сообщением об отсутствии каталога.

API требует авторизации, принимает только поддержанные жанры и положительные номера страниц. Сервер использует существующий Last.fm-ключ, кеш на шесть часов и объединение одинаковых запросов; одновременно допускается до 64 разных ожидающих запросов. Ошибки не кешируются как пустой результат. Портреты загружаются отдельно с ограниченной параллельностью и кешем отсутствующих изображений.

Жанры основаны на тегах сообщества, поэтому их классификация может быть неточной. Одноимённые исполнители и качество портретов остаются отдельной задачей. Изменение не затрагивает плеер, скачивания, историю и сохранение профиля.
