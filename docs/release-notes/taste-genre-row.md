# Адаптивная полоса жанров

Полоса быстрых фильтров использует все 34 подключённых направления: количество видимых кнопок определяется шириной контейнера и фактической шириной подписей. Выбранный фильтр сохраняется первым, даже при сужении окна; на особо узком экране длинная подпись сокращается. Остальные жанры доступны в сгруппированной панели «Все жанры». Кнопка панели расположена рядом с фильтрами и выделена тонкой фиолетовой рамкой, лёгкой заливкой и иконкой.

Список Яндекса содержит дополнительные поджанры и региональные категории. Они не объявлены поддерживаемыми без подходящего источника данных. Фильтры Soundspan используют community tags Last.fm: жанровая принадлежность может быть неоднозначной, это не классификатор Яндекса. Фильтр определяет каталог исполнителей; сохранённые исполнители становятся исходными предпочтениями рекомендаций, но не задают строгий жанровый запрет на остальные треки.

Публичный production API проверен для всех 34 направлений: по 48 артистов на первой странице, nextPage=2; проверены 401 без авторизации и 400 для неизвестного жанра/неверной страницы. Профили пользователей при проверке не изменялись.

Регрессия: широкий контейнер показывает больше прежних шести фильтров, узкий сокращает их число, выбор из полной панели остаётся видимым и повторное расширение восстанавливает дополнительные кнопки.
