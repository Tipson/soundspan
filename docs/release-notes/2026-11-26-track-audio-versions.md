# Полные версии треков

Администратор может загрузить MP3 к точной записи каталога, прослушать черновик, опубликовать или снять с публикации. Обновлённые веб-плеер и Android выбирают опубликованную дорожку для сетевого воспроизведения. Пункт «Стандартная версия» в Android переключает текущую запись очереди.

- verify: Prisma проверила схему. Серверные тесты покрывают доступ, диапазоны байтов, замену черновика, снятие с публикации и отсутствующий файл.
- verify: 58 целевых веб-тестов и production-сборка Next.js прошли. Обе реализации прокси проверены на выдачу авторизации строго для чтения аудио.
- verify: 118 целевых Flutter-тестов, статический анализ и debug-сборка прошли. Тесты очереди проверяют сохранение выбора и защиту от действия по уже сменившемуся треку.

Доказательства относятся к локальной сборке. Применение миграции на рабочей базе, выкладка на сервер и запуск на физическом устройстве проверяются отдельно.
