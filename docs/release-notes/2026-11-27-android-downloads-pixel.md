# Прокрутка загрузок на Pixel 7a

Проверка исправления `5568195f` выполнена на Pixel 7a с Android 17. Debug APK `0.1.27+30` собран поверх этой правки и включает рабочую копию изменений полных версий треков.

- verify: установленный APK и локальный файл совпали по SHA-256 `68125c291a815b10c42c450e110cc880befb4050e3c41d30cfac7da68b28cd1c`.
- verify: после входа в приложение два прогона жестами от начала списка загрузок до низа и обратно. Поиск полностью уходил за пределы экрана и возвращался. При втором прогоне панель «Память и автозагрузка» осталась раскрыта. Бордового блока на экране и ошибок `PageStorage` или `ErrorWidget` в журнале приложения не обнаружено.

Проверка относится к установленному на Pixel файлу. APK на устройстве, где был сделан исходный скриншот, не сравнивался.
