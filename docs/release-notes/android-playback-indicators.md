# Android: индикация треков и обновление офлайн-оболочки

## Изменения

- Общий индикатор рядом с названием в загрузках, популярных треках и стандартных списках альбомов. На паузе движение останавливается; reduced motion учитывается.
- Сопоставленные записи Last.fm распознают текущий YouTube-трек по каноническому идентификатору, а не только по id строки. Локальные файлы не объединяются по резервным метаданным источника.
- У текущего трека убраны дублирующие иконка и бейдж «В очереди».
- Каждая production-сборка меняет байты service worker через BUILD_ID, чтобы повторно сохранялась офлайн-оболочка. Копии аудио и политика отложенной активации не меняются.
