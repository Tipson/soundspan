# Лента жанров и действие настройки вкусов

Полные названия жанров отображаются в горизонтальной ленте с постоянным порядком. Лента поддерживает сенсорную прокрутку, клавиатуру и стрелки; на краях соответствующая стрелка неактивна. Выбор из полной панели подводит нужный жанр в область просмотра, не переставляя категории. Панель «Все жанры» сохранена.

На desktop заголовок и действие настройки расположены в левой колонке. На мобильном устройстве действие остаётся в нижней панели. Декоративное фиолетовое заполнение плавно реагирует на количество выбранных предпочтений и уменьшается при отмене выбора; это не индикатор обязательного количества и не прогресс сетевой операции. Сохранение одного исполнителя и очистка выбора доступны; ограничений количества нет. Во время запроса отображается отдельное состояние сохранения. Reduced motion отключает декоративные переходы и плавную прокрутку.

Порядок работы: регрессионные тесты → интерфейс → сборка и тесты → narrow frontend release → проверка desktop/mobile на production → запись результата в Obsidian. Backend, воспроизведение и профили пользователей в UI-проверках не изменяются.
