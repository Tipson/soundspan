# 2026-09-26 — Персональные миксы по направлениям

Вместо трёх очередей, переставлявших один и тот же набор рекомендаций, главная показывает до трёх миксов по выбранным жанрам или исполнителям. Если настройка вкуса пропущена, направления берутся из понравившихся и успешно прослушанных исполнителей. Для жанров используются артисты каталога; поиск песен дополняет короткие очереди радио. Знакомые песни смешиваются с находками, дизлайки исключаются, повторные видео между направлениями не показываются. Очередь каждого микса ограничена 40 треками; направление с менее чем 20 доступными треками скрывается. Если отдельных направлений не получилось, остаётся один общий микс. «Открытия недели» и подборка по местному времени суток сохранены.

Новый авторизованный маршрут `GET /api/personalized/daily-mixes` формирует ответ для текущего аккаунта. Ограничены число направлений, запросов к каталогу и размер очередей; одинаковые запросы одного аккаунта объединяются и ненадолго кэшируются. Запрос из браузера и его прокси имеют достаточное время для холодного построения.
