## Исправления

- Отказ CDN после начала передачи: одна новая ссылка, сверка размера и SHA-256
  переданного префикса, продолжение того же файла. Повторный отказ ограничен
  исходным дедлайном; отмена и несовпадение содержимого прерывают восстановление.
- Событие `playing` на буферизованном фрагменте не обнуляет три автоматические
  попытки нативного плеера.
- Публичные данные композиции не зависят от личной YouTube-сессии. Upstream `401`
  становится `502` и не завершает сессию Soundspan.
- Быстрый Last.fm-поиск отменяет очередь, ожидание повторов и активный HTTP-запрос;
  дополнительные запросы обогащения каждого результата исключены из этого пути.
- API и worker согласуют каждый MusicBrainz HTTP-запрос через Redis. После
  `429/503` действует общая пауза, а неуспешный поиск не кешируется как отсутствие
  записи на один час.
- Перекрывающиеся отметки показов сериализуются по принадлежащей пользователю
  выдаче. Повторные запросы сохраняют первоначальный `viewedAt`.

Контракты описаны в [дизайне восстановления](../designs/playback-reliability.md).

## Открытые ограничения

- MusicBrainz продолжает возвращать внешние `503`. Координация и пауза работают;
  доступность стороннего сервиса этим выпуском не гарантируется.
- Постоянное отсутствие CAPTCHA не доказано. Восстановление после внесённого
  отказа и короткое наблюдение production не заменяют длительную проверку.
- Реальный телефон, блокировка экрана и смена мобильной сети не проверены.
- Полный Python mypy-gate остаётся красным: 210 прежних ошибок в 19 тестовых
  файлах. Снимок исходного HEAD дал точно такой же набор ошибок; изменённый
  runtime и добавленные тесты прошли отдельную строгую проверку.
- Неизменённый тест освобождения traceback после отмены DCLAP проходит на
  Python 3.13, но не проходит на 3.12, используемом production DCLAP. Рост памяти
  production из-за этого случая не доказан; изменение DCLAP не включено в выпуск.
- Стартовое предупреждение Bull MaxListeners воспроизведено и связано с
  одновременными ожиданиями Redis-ready при регистрации обработчиков. В библиотеке
  предусмотрено удаление этих временных слушателей; лимиты не повышались,
  предупреждения не скрывались.
