**Персональная музыкальная платформа: своя Волна, длинные миксы, новые открытия и музыка офлайн.**

Soundspan объединяет онлайн-источники и собственную музыкальную библиотеку в одном веб-приложении. Вы выбираете любимых исполнителей, слушаете музыку и оцениваете треки — рекомендации учитывают ваши предпочтения и историю. Платформу можно установить на свой сервер, а приложение — на телефон через PWA.

## Музыка под ваш вкус

| Возможность                      | Как работает                                                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Моя волна**                    | Персональный поток с учётом вкусов, прослушиваний, лайков и дизлайков. Отбор учитывает недавние повторы и разнообразие исполнителей.                          |
| **Миксы дня**                    | До шести подборок по музыкальным направлениям. Сформированные миксы содержат 20–40 треков; их количество зависит от доступной музыки и вашего профиля.        |
| **Открытия недели**              | Подборка новой для вас музыки с целью до 40 треков. Состав сохраняется на неделю; новая неделя начинается в понедельник UTC и собирается при первом открытии. |
| **Утро, день, вечер, ночь**      | Подборки учитывают местное время и привычки прослушивания в соответствующий период.                                                                           |
| **Радио по треку и исполнителю** | Можно продолжить слушать похожую музыку, сохранив исходное направление радио при пополнении очереди.                                                          |
| **Настройка вкусов**             | Полноэкранный выбор исполнителей, жанры, поиск и подгрузка каталога при прокрутке. Количество выбранных артистов и жанров не ограничено.                      |
| **Несколько источников**         | YouTube Music, подключённые VK/Яндекс и локальная библиотека. Доступные источники выбираются автоматически с проверкой соответствия записи.                   |
| **Слушать офлайн**               | Заранее загруженные на устройство треки доступны без сети, включая запуск сохранённого приложения.                                                            |

## На компьютере и телефоне

Soundspan работает в браузере и устанавливается как PWA. На телефоне доступны компактный и полноэкранный плееры, очередь, оценки треков и системные медиакнопки. Загружайте музыку при наличии сети, чтобы слушать её позже офлайн.

## Своя музыка и коллекция

- Локальная библиотека с метаданными, обложками и поиском.
- Плейлисты, любимые треки и история отдельно для каждого пользователя.
- Импорт плейлистов из Spotify и Deezer с сопоставлением записей в доступных источниках.
- Совместное прослушивание через Listen Together.
- Совместимый OpenSubsonic API для сторонних клиентов.

Дополнительные интеграции включают Last.fm/ListenBrainz, Lidarr, Soulseek и Audiobookshelf. Подкасты и аудиокниги также поддерживаются; подключение описано в [руководстве по интеграциям](docs/INTEGRATIONS.md).

## Развернуть на своём сервере

Этот репозиторий содержит нашу версию Soundspan. Для её установки собирайте образы из исходников. Образы `ghcr.io/soundspan/*` относятся к исходному проекту и не включают изменения этого репозитория.

Нужны Git, Docker Engine или Docker Desktop и Docker Compose v2 с поддержкой `additional_contexts`.

```bash
git clone https://github.com/Tipson/soundspan.git
cd soundspan
cp .env.example .env
```

Перед запуском отредактируйте `.env`:

| Переменная                | Значение                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `MUSIC_PATH`              | Абсолютный путь к существующему каталогу музыки на сервере.                                                                                     |
| `POSTGRES_PASSWORD`       | Отдельный случайный пароль базы данных.                                                                                                         |
| `SESSION_SECRET`          | Случайный секрет длиной не менее 32 символов.                                                                                                   |
| `SETTINGS_ENCRYPTION_KEY` | Отдельный случайный ключ шифрования настроек.                                                                                                   |
| `INTERNAL_API_SECRET`     | Отдельный случайный секрет для связи сервисов, не менее 32 символов.                                                                            |
| `DATABASE_URL`            | Оставьте пустым: контейнеры используют адрес PostgreSQL из Compose. Значение `localhost:5433` из примера предназначено для разработки на хосте. |
| `BACKEND_PROCESS_ROLE`    | `api`: фоновые задачи выполняет отдельный worker.                                                                                               |

Для каждого пароля и секрета можно отдельно выполнить `openssl rand -base64 32`. Сохраните значения: они нужны при последующих запусках и восстановлении.

Запуск основного приложения и YouTube Music sidecar из исходников:

```bash
docker compose -f docker-compose.yml --profile worker up -d --build \
  postgres redis backend backend-worker frontend ytmusic-streamer
```

Откройте `http://localhost:3030/onboarding` и создайте первого администратора до публикации сервера в интернете. Настройте внешние источники и необходимые ключи интеграций. Для установки PWA и публикации приложения используйте HTTPS.

Аудиоанализ и DCLAP подключаются отдельно; приведённая команда их не запускает. Варианты установки, готовые образы своего форка, настройки источников и обновления описаны в [Deployment Guide](docs/DEPLOYMENT.md), [Integration Guide](docs/INTEGRATIONS.md) и [справочнике переменных](docs/ENVIRONMENT_VARIABLES.md).

## Что важно учитывать

- Онлайн-каталог зависит от доступности и настроек внешних источников. Soundspan не хранит собственную копию каталога Spotify или Яндекса.
- Персональные подборки требуют подходящей доступной музыки и данных о вкусах. На новом аккаунте их может быть меньше; изменения оценок могут уменьшать сохранённую недельную выдачу.
- Онлайн-открытия недели используются, когда нет готовой недельной подборки из локальной библиотеки. Настроенный локальный режим имеет приоритет.
- Офлайн доступна музыка, заранее сохранённая на конкретном устройстве. Поиск и новые рекомендации требуют сети.
- Фоновое воспроизведение, системные кнопки и хранение PWA зависят от браузера и операционной системы.
- Межисточниковое сопоставление учитывает подтверждённую запись; универсальная дедупликация всех версий песни остаётся направлением развития.

## Дальнейшее развитие

- Синхронизация очереди и позиции между устройствами с одним активным устройством воспроизведения.
- Более точное различение версий записей и защита от повторов между каталогами.
- Улучшение качества Волны и миксов по реальным прослушиваниям и обратной связи.
- Проверка фонового и офлайн-прослушивания на Android и iPhone.
